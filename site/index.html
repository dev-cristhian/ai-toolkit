Hub pessoal de IA

Skills, agents e MCPs para turbinar seu trabalho com IA

O ai-toolkit reúne em um só lugar o que eu uso e recomendo para trabalhar com IA no dia a dia: itens que eu mesmo mantenho e uma seleção dos melhores itens da comunidade. Tudo é instalado com um único comando no Claude Code, Cursor, Codex e VS Code + GitHub Copilot.

macOS e Linux 
curl -fsSL https://raw.githubusercontent.com/dev-cristhian/ai-toolkit/main/install.sh | bash
Windows (PowerShell) 
irm https://raw.githubusercontent.com/dev-cristhian/ai-toolkit/main/install.ps1 | iex

O instalador mostra o plano e pede confirmação antes de mudar qualquer coisa. Para só visualizar, use a opção --dry-run (veja Como instalar).

Ver o catálogo Repositório no GitHub

Para quem é?

  • Devs que usam IA para programar e querem um bom ponto de partida.
  • Pessoas de QA, produto e negócio que querem levar a IA para discovery, specs e testes.
  • Quem quer entender os termos de IA sem complicação (veja o glossário logo abaixo).

Glossário de IA

Os termos mais usados no mundo da IA, explicados em português simples. Os nomes ficam em inglês, como a comunidade usa no dia a dia.

Categoria

30 termos

Agentic workflow
Agents e ferramentas

Fluxo de trabalho em que a IA executa várias etapas com certa autonomia (planejar, executar, verificar, corrigir), em vez de responder uma pergunta isolada.

Agents
Agents e ferramentas

Um LLM que não só responde, mas age: planeja etapas, usa ferramentas (ler arquivos, rodar comandos, pesquisar na web), observa o resultado e repete até concluir a tarefa.

Exemplo: Pedir “corrija o teste que está falhando” e o agent abrir os arquivos, rodar os testes, editar o código e rodar de novo.

Chain-of-thought Prompting
Prompting e contexto

Pedir que a IA mostre o raciocínio passo a passo antes da resposta final. Isso costuma melhorar o resultado em problemas que exigem várias etapas.

Exemplo: “Pense passo a passo antes de responder: quanto custa o pedido com frete e desconto?”

Context engineering
Prompting e contexto

Evolução do prompt engineering: cuidar de tudo o que entra na context window (instruções, documentos, ferramentas, histórico, memória) para que o modelo tenha exatamente a informação certa, sem excesso.

Context window
Prompting e contexto

A “memória de curto prazo” do modelo: o máximo de tokens que ele consegue considerar de uma vez, somando suas instruções, arquivos, histórico da conversa e a própria resposta. O que passa do limite é cortado ou resumido.

Embeddings
Dados e RAG

Uma forma de transformar texto (ou imagens) em uma lista de números que representa o significado. Textos com sentido parecido ficam com números próximos, o que permite buscar por significado, e não só por palavra exata.

Exemplo: Buscar “como cancelar meu plano” e encontrar o artigo “Encerrar assinatura”.

Emergent Behavior
Fundamentos

Habilidade que aparece em modelos grandes sem ter sido ensinada diretamente, como resolver problemas em etapas ou traduzir entre idiomas pouco vistos no treino.

Fine-tuning
Modelos

Treinar um pouco mais um modelo que já existe, com seus próprios exemplos, para especializá-lo em uma tarefa, um tom de voz ou um domínio.

Exemplo: Ajustar um modelo com milhares de respostas do seu suporte para que ele responda no padrão da empresa.

Generative AI
Fundamentos

IA que cria conteúdo novo (texto, código, imagem, áudio ou vídeo) a partir de um pedido, em vez de apenas classificar ou prever algo.

Exemplo: Pedir “escreva um e-mail de boas-vindas para novos clientes” e receber o texto pronto.

Hallucination
Modelos

Quando a IA inventa algo com total confiança: um fato, uma citação, uma função de biblioteca que não existe. Por isso é importante conferir e dar fontes confiáveis no contexto.

Exemplo: O modelo sugere um método .toSmartJSON() que nunca existiu na biblioteca.

Large Language Model (LLM)
Modelos

Modelo de IA treinado com uma quantidade enorme de texto para prever a próxima palavra (token). Disso surge a capacidade de conversar, resumir, traduzir e escrever código.

Exemplo: Claude, GPT, Gemini e Llama são LLMs.

MCP (Model Context Protocol)
Agents e ferramentas

Padrão aberto para conectar IAs a ferramentas e fontes de dados. Um “MCP server” expõe ferramentas, e qualquer app compatível (Claude, Cursor, Codex, Copilot) consegue usá-las. Funciona como uma “tomada universal” para a IA.

Exemplo: Com o Playwright MCP, o agent consegue abrir um navegador e testar sua aplicação.

Meta Prompt / System Prompt
Prompting e contexto

Instruções de fundo que valem para a conversa inteira e definem o papel, as regras e o tom da IA. Normalmente o usuário final não vê.

Exemplo: “Você é um assistente de suporte da Loja X. Responda sempre em português e nunca prometa prazos.”

Multi-agent system
Agents e ferramentas

Vários agents trabalhando juntos, cada um com um papel (por exemplo: um planeja, outro programa, outro revisa), trocando resultados entre si.

Multimodal Model
Modelos

Modelo que entende (e às vezes gera) mais de um tipo de conteúdo: texto, imagem, áudio, vídeo.

Exemplo: Enviar o print de uma tela com erro e perguntar o que está errado.

Natural Language Processing (NLP)
Fundamentos

Área da computação que ensina máquinas a entender e produzir a linguagem que as pessoas falam e escrevem. Os LLMs são a geração mais recente dessa área.

Exemplo: Tradutores automáticos, corretores ortográficos e chatbots usam NLP.

Neural Networks
Fundamentos

Modelos matemáticos inspirados, de forma bem simplificada, nos neurônios do cérebro. São camadas de “unidades” conectadas que aprendem padrões a partir de muitos exemplos.

Parameters
Fundamentos

Os números internos que um modelo ajusta durante o treinamento; é ali que fica o que ele “aprendeu”. Mais parameters costumam significar mais capacidade, mas também mais custo para rodar.

Exemplo: Quando se fala em “modelo de 70B”, são 70 bilhões de parameters.

Prompt Engineering
Prompting e contexto

A prática de escrever bons pedidos (prompts) para a IA: dar contexto, objetivo, formato esperado, exemplos e restrições claras para obter respostas melhores.

Exemplo: Em vez de “melhore esse texto”, dizer “reescreva para um público leigo, em até 3 parágrafos, mantendo os números”.

RAG (Retrieval-Augmented Generation)
Dados e RAG

Técnica em que, antes de responder, o sistema busca trechos relevantes nos seus documentos e os coloca no prompt. Assim a IA responde com base em informação atual e própria, reduzindo hallucination.

Exemplo: Um chatbot que consulta o manual interno da empresa antes de responder ao funcionário.

Reasoning Models
Modelos

Modelos que “pensam antes de responder”: gastam mais tempo e tokens raciocinando em etapas internas antes de dar a resposta final. Costumam ir melhor em matemática, lógica e código complexo.

References
Prompting e contexto

Materiais de apoio que você entrega à IA para ela se basear: documentação, guias de estilo, exemplos, links. Em skills, costumam ficar numa pasta references/ e são lidos só quando necessários, economizando contexto.

Exemplo: A skill web-design-guidelines guarda suas regras de acessibilidade em references/guidelines.md.

Reinforcement Learning
Fundamentos

Forma de treinar por tentativa e erro: o modelo recebe “recompensas” quando acerta e “penalidades” quando erra, e aprende a preferir o que dá certo. É muito usada para deixar LLMs mais úteis e seguros (por exemplo, RLHF, com feedback humano).

Skill
Agents e ferramentas

Um pacote de instruções (um arquivo SKILL.md, mais referências e scripts opcionais) que ensina o agent a fazer uma tarefa específica do seu jeito. O agent só carrega a skill quando ela é relevante.

Exemplo: A skill grill-me faz o agent entrevistar você sobre um plano antes de começar a programar.

Subagent
Agents e ferramentas

Um agent especializado que o agent principal chama para uma tarefa específica. Ele trabalha com seu próprio contexto e instruções e devolve só o resultado, mantendo a conversa principal enxuta.

Exemplo: O agent web-pending-change-auditor deste hub é um subagent de code review.

Temperature (AI Temperature)
Modelos

Configuração que controla o quanto a resposta é previsível ou criativa. Temperature baixa dá respostas mais consistentes; alta dá respostas mais variadas (e mais arriscadas).

Exemplo: Para gerar código, use temperature baixa; para ideias de nomes de produto, uma mais alta.

Token
Fundamentos

O pedacinho de texto que o modelo lê e escreve: pode ser uma palavra, parte de uma palavra ou um sinal de pontuação. Limites e preços das IAs são contados em tokens.

Exemplo: “Desenvolvimento” pode virar 3 ou 4 tokens; em português, 1 token fica em média em torno de 3 a 4 caracteres.

Tool use / Function calling
Agents e ferramentas

Capacidade do modelo de pedir a execução de uma ferramenta ou função externa (buscar na web, consultar uma API, ler um arquivo) e usar o resultado na resposta.

Exemplo: O modelo chama get_weather("São Paulo") em vez de chutar a previsão do tempo.

Transformer Model
Modelos

A arquitetura de rede neural por trás de quase todos os LLMs atuais. A ideia central (“attention”) permite que o modelo olhe para todas as partes do texto ao mesmo tempo e entenda quais palavras se relacionam.

Vector database
Dados e RAG

Banco de dados feito para guardar embeddings e encontrar rapidamente os mais parecidos com uma busca. É uma peça comum em sistemas de RAG.

Exemplo: pgvector (PostgreSQL), Qdrant, Pinecone e Azure AI Search.

Nenhum termo encontrado. Tente outra palavra ou escolha “Todos”.

Como instalar

Escolha a sua ferramenta. O instalador mostra tudo o que vai fazer e pede confirmação antes de mudar qualquer coisa. O passo a passo completo está no README.

Claude Code

Pré-requisitos: Node.js 22.20 ou mais recente, Git e o Claude Code instalado (o comando claude precisa estar no PATH para registrar os MCPs).

macOS e Linux 
curl -fsSL https://raw.githubusercontent.com/dev-cristhian/ai-toolkit/main/install.sh | bash -s -- --target claude
Windows (PowerShell) 
& ([scriptblock]::Create((irm https://raw.githubusercontent.com/dev-cristhian/ai-toolkit/main/install.ps1))) --target claude

Onde cada item é instalado

Skills
~/.claude/skills/ (atalho para a cópia em ~/.agents/skills/)
Agents
~/.claude/agents/
MCPs
~/.claude.json (via claude mcp add --scope user)

Como conferir: Abra uma nova sessão do Claude Code: /agents lista os agents, /mcp mostra os MCPs e você pode perguntar “quais skills você tem?”.

No app do Claude (claude.ai), as skills podem ser enviadas como .zip em Configurações → Capabilities → Skills.

Cursor

Pré-requisitos: Node.js 22.20 ou mais recente, Git e o Cursor instalado.

macOS e Linux 
curl -fsSL https://raw.githubusercontent.com/dev-cristhian/ai-toolkit/main/install.sh | bash -s -- --target cursor
Windows (PowerShell) 
& ([scriptblock]::Create((irm https://raw.githubusercontent.com/dev-cristhian/ai-toolkit/main/install.ps1))) --target cursor

Onde cada item é instalado

Skills
~/.agents/skills/ (pasta compartilhada que o Cursor lê direto)
Agents
~/.cursor/agents/
MCPs
~/.cursor/mcp.json

Como conferir: Reinicie o Cursor e abra Cursor Settings → MCP para ver os servidores. As skills e os agents aparecem no chat do agent.

Codex

Pré-requisitos: Node.js 22.20 ou mais recente, Git e o OpenAI Codex (CLI, app ou extensão).

macOS e Linux 
curl -fsSL https://raw.githubusercontent.com/dev-cristhian/ai-toolkit/main/install.sh | bash -s -- --target codex
Windows (PowerShell) 
& ([scriptblock]::Create((irm https://raw.githubusercontent.com/dev-cristhian/ai-toolkit/main/install.ps1))) --target codex

Onde cada item é instalado

Skills
~/.agents/skills/ (pasta compartilhada que o Codex lê direto)
Agents
~/.codex/agents/*.toml (convertidos automaticamente de Markdown para TOML)
MCPs

Como conferir: Rode codex mcp list para ver os MCPs e, numa nova sessão, peça ao Codex para listar as skills disponíveis.

VS Code + Copilot

Pré-requisitos: Node.js 22.20 ou mais recente, Git, VS Code e a extensão do GitHub Copilot.

macOS e Linux 
curl -fsSL https://raw.githubusercontent.com/dev-cristhian/ai-toolkit/main/install.sh | bash -s -- --target copilot
Windows (PowerShell) 
& ([scriptblock]::Create((irm https://raw.githubusercontent.com/dev-cristhian/ai-toolkit/main/install.ps1))) --target copilot

Onde cada item é instalado

Skills
~/.agents/skills/ (pasta compartilhada que o Copilot lê direto)
Agents
~/.copilot/agents/*.agent.md
MCPs
~/.copilot/mcp-config.json

Como conferir: Recarregue o VS Code. No Chat, abra o seletor de agents para ver os agents; o comando MCP: List Servers mostra os MCPs.

Opções úteis: --level 1, --type mcp, --only own, --id grill-me, --scope project (instala só na pasta atual), --dry-run e --yes. Para MCPs de terceiros, o instalador sempre lista os comandos e URLs antes de registrar.
